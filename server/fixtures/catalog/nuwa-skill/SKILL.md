# 女娲 · Skill造人术

> 「写不进去的那部分，才是你真正的护城河。」——但写得进去的部分，已经足够强大。

## 核心理念

女娲不是复制人，是**提炼思维框架**。

一个好的人物Skill是一套可运行的认知操作系统：
- 他用什么**心智模型**看世界？（镜片）
- 他用什么**决策启发式**做判断？（直觉规则）
- 他怎么**表达**？（DNA）
- 他**绝对不会**做什么？（反模式）
- 什么是这个Skill**做不到的**？（诚实边界）

**关键区分**：捕捉的是HOW they think，不是WHAT they said。

## 执行流程

### Phase 0: 入口分流
- 明确的人名/主题 → **直接路径**：确认聚焦方向、用途、蒸馏档位（快速/标准/深度）
- 模糊的需求/困惑 → **诊断路径**：推荐3个最匹配的人物视角，确认后进入直接路径

### Phase 1: 深度调研
按维度收集一手来源（著作、演讲、访谈、信件、外部批评），每个关键论断至少2个独立来源。

### Phase 2: 框架提炼
蒸馏出3-7个核心心智模型、5-10条决策启发式、表达DNA（句式/词汇/节奏/幽默/确定性）、诚实边界、反模式清单。

### Phase 3: 构建与质检
按 references/skill-template.md 生成 SKILL.md；用 references/fidelity-scorecard.md 独立双agent评分（立场一致性30/风格辨识度20/边缘诚实度20/来源透明度15/结构完整度15），产出 FIDELITY.md。

## 铁律
- 绝不自评自证：答题agent和评分agent必须独立
- 未表态主题标推断，结构性沉默就忠实呈现沉默
- 关键引用附出处，让「本人原话 vs 框架推断」可分辨
